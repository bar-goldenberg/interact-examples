# Legacy prompts

Kept for reference only. Nothing here is live.

These 7 guidelines were generated by the **old `/interact-demo-to-guideline`
skill** and used to live in `Ani-Mate Prompts/`. They were moved aside so the
example library could be rebuilt from scratch in the new format.

## Why they were replaced

The old skill's brief was to turn a demo into a layout-agnostic specification —
the author never sees the target section, so the guideline has to be the entire
source of truth. That is not satisfiable: writing a role model and a mapping
procedure means committing to what the target looks like, so the author ends up
encoding a *second*, imagined layout that is exactly as rigid as the demo's,
minus the runnable reference.

Those assumptions then harden into requirements. `3d-small-carousel.md` §9
demands separate stage and ring selectors and rejects content-stack items — but
a real Wix section has neither, so by its own procedure the guideline rejects the
section and the agent can only return nothing or force-fit and break.

## What replaced them

The `interact-example-builder` skill, which keeps the demo instead of abstracting
it. An example is a sanitized **runnable** demo plus a short note covering only
what the code cannot say, and the general "how do I map this onto a section that
doesn't match" advice moved into shared globals (house rules + adaptation ladder)
that ship with every generation rather than being restated ~170 times.

New examples are written to `Ani-Mate Prompts/`.
